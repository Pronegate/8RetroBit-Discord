# 8RetroBit

Landing page del server Discord 8RetroBit — arcade/retrogaming, in stile pixel/synthwave.

## Contenuto

- `index.html` — pagina unica, autosufficiente (HTML + CSS + JS inline, immagini incorporate). Nessuna build, nessuna dipendenza da installare.

## Pubblicarla online gratis (GitHub Pages)

1. Crea un repository pubblico su GitHub (es. `8retrobit-site`).
2. Carica `index.html` nella root del repository.
3. Vai su **Settings → Pages**, imposta la sorgente sul branch `main` (root `/`).
4. Dopo un minuto la pagina è online su `https://<tuo-utente>.github.io/8retrobit-site/`.
5. (Opzionale) collega un dominio tuo da **Settings → Pages → Custom domain**.

## Modificarla in locale

Basta aprire `index.html` in un browser — nessun server richiesto.
